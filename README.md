# 中华万年黄历 V1 H5

这是《中华万年黄历与传统时间文化解释器》V1 的公开静态验收站点，仅用于 GitHub Pages 手机网页体验。

- 正式源码保存在独立私有仓库 `mina426w-ux/chinese-almanac-explainer`。
- 本仓库只包含由正式源码构建出的静态站点、第三方声明和 Pages 工作流。
- H5 与微信小程序共用同一份 `lunar-javascript@1.7.7`、黄历计算模块、时区配置和三层注解数据；没有另写黄历算法。
- 支持日期范围为 `1901-01-01` 至 `2100-12-31`，规则集名称为“V1传统黄历规则集”。
- 页面无需账户、服务器或运行时网络 API。

发布地址：<https://mina426w-ux.github.io/chinese-almanac-explainer-h5/>

传统文化说明：宜忌、冲煞、神煞和方位属于传统历书分类，不是现代科学结论，也不替代现实中的医疗、法律、财务、安全或工程判断。
